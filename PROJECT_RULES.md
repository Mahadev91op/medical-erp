# Project Rules & Context

## Project Name
Medical ERP

## Stack
- **Framework:** Next.js
- **Database:** MongoDB
- **Backend/API:** Express / Next.js API Routes
- **Styling:** Tailwind CSS

## Coding Rules
- **No duplicate code:** Avoid redundancy; extract common logic.
- **Always optimize:** Keep performance, database queries, and rendering optimized.
- **Always reusable:** Design components and utility functions to be reusable.
- **Always modular:** Keep code modular and cleanly separated.
- **Always production ready:** Write clean, readable, well-structured, and error-handled code.
- **Never break existing code:** Regression testing and backwards compatibility are key.
- **Always check for bugs:** Perform thorough checks and handle edge cases/errors gracefully.
- **Always test:** Ensure code logic is validated and runs correctly.
- **Always explain changes:** Document and explain modifications clearly.
- **Never remove existing feature unless asked:** Preserve current features and functionality.
